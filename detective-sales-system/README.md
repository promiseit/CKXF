# 神探销售系统

一个用探案思路分析客户的销售工具，帮助你从客户的话语、文件、图片等中发现潜在需求，抓住销售机会。

## 🎯 核心功能

### 1. 案件管理
- 创建新案件（客户项目）
- 查看案件列表
- 编辑/删除案件

### 2. 线索收集
- 添加文本线索
- 标记线索重要性（1-5星）
- 为线索添加标签
- 按时间轴展示线索

### 3. 分析推理（层层递进）
- **第一层**：基础事实梳理
- **第二层**：关联线索发现
- **第三层**：潜在需求推断
- **第四层**：行动方案建议

### 4. 报告生成
- 自动生成分析报告
- 导出PPT演示文稿（模拟）

### 5. 国产大模型集成
- 预留AI模型接口，可后续扩展

## 🚀 快速开始

### 方法一：直接打开
1. 下载项目到本地
2. 直接打开 `index.html` 文件即可使用

### 方法二：本地服务器（推荐）
```bash
# 进入项目目录
cd detective-sales-system

# 启动本地服务器（使用Python）
python3 -m http.server 8000

# 或使用Node.js
npx http-server -p 8000

# 然后在浏览器中访问 http://localhost:8000
```

## 🌟 特色功能

1. **探案流程**：模拟侦探破案的流程，层层递进分析客户需求
2. **轻量化**：纯前端实现，无需后端服务器
3. **响应式**：支持桌面端和移动端
4. **智能提示**：实时保存数据，操作有反馈
5. **示例数据**：内置示例案件，方便快速上手

## 📝 使用说明

1. **创建案件**：点击"新建案件"按钮，填写客户信息
2. **收集线索**：在案件详情页点击"添加线索"，录入客户相关信息
3. **分析推理**：在分析推理模块，按照四个层次进行分析
4. **生成报告**：点击"生成报告"查看分析结果
5. **导出PPT**：点击"导出PPT"生成演示文稿（模拟功能）
6. **案件状态**：点击"下一步"更新案件状态
